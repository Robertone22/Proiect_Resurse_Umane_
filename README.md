# Proiect C++ - Gestionare Resurse Umane

## Descriere
Acest proiect implementează o structură de tip firmă cu moșteniri, polimorfism, funcții virtuale și gestionare prin HR.

## Caracteristici
- Clasă de bază `Angajat` și clase derivate: `Manager`, `Intern`, `HrManager`
- Funcții virtuale și clone
- Apeluri virtuale prin pointeri la clasa de bază
- Fișiere de intrare
- Excepții (pot fi extinse)
- STL și smart pointers

## Structură
- `include/` - Header-ele claselor
- `src/` - Implementările claselor și `main.cpp`
- `angajati.txt` - Datele de intrare
- `README.md` - Documentație
